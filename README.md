# Collaborative Kanban

A web-based Kanban task management application.

## Features

- User login
- Kanban board
- To Do, In Progress, Testing and Done columns
- Add new tasks
- Move tasks between columns
- Delete tasks
- Browser local storage for tasks and login information
- Responsive interface

## Project Structure

```text
collaborative-kanban/
├── frontend/
│   ├── index.html
│   ├── style.css
│   └── app.js
├── .env.example
├── .gitignore
└── README.md
```

## Run

1. Download or clone the project.
2. Open `frontend/index.html` in a browser.
3. Enter a name and email to log in.
4. Use the Kanban board to add, move and delete tasks.

- HTML
